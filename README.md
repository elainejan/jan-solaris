# ☀️ SOLARIS — Interactive Solar System Explorer

Explore the solar system through an interactive experience featuring the Sun, planets, and dwarf planets.

## ✨ Features

- 🪐 Interactive solar system visualization
- 🔍 Search and explore celestial bodies
- 📚 Learn about the solar system
- 🚀 Discover missions and space exploration
- ⚖️ Compare planets and their characteristics
- 🎲 Surprise Me feature for random discoveries

## 🎮 Explore

Navigate the solar system, select celestial bodies, and discover more about our cosmic neighborhood.
